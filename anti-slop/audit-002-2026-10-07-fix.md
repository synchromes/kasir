# Perbaikan audit 002

Pengguna menyetujui temuan 1-10 dan meminta lebar kartu POS 400px.

1. Kontras: accent menjadi #00714D; putih di atasnya 6,05:1. Outline menjadi #666979; teks pada surface 5,16:1. Keduanya lolos AA untuk teks normal.
2. Tombol tutup dialog: nama aksesibel, area 44px, indikator fokus.
3. Upload produk: tombol native yang bisa membuka pemilih file lewat keyboard dan sentuhan.
4. Label filter produk, kategori/satuan produk, tanggal laporan terhubung; link detail transaksi menyebut invoice.
5. Target tutup dialog, tanggal, preset laporan, ekspor, poin POS, dan tautan panel notifikasi diperbesar.
6. Notifikasi: gagal muat dibedakan dari kosong, ada coba lagi; kegagalan mutasi diberi pesan. Daftar notifikasi tidak mengubah status lokal sebelum server berhasil.
7. Escape menutup panel dan mengembalikan fokus ke bel.
8. Pesan stok nol memakai titik, ekspektasi tes diperbarui.
9. Metrik stok/laporan memakai sentence-case.
10. Mobile memakai token warna berdasarkan kelompok kerja, bukan hash. Kartu terlaris memakai primary; status memakai token semantik. DESIGN.md diperbarui.

Kolom kanan POS di desktop menjadi 400px, sehingga pesanan, keranjang, dan total mengikuti lebar yang sama. Mobile tetap mengikuti lebar layar.
