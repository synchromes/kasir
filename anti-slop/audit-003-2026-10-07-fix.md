# Perbaikan audit 003: konsistensi warna

Semua temuan 1-7 diperbaiki.

1. Grafik: laba memakai accent gelap; batang non-tunai memakai on-surface-variant; token `chart-1` sampai `chart-6` ditambahkan untuk data kategorikal.
2. Metode pembayaran: CASH, QRIS, dan TRANSFER kini memiliki warna tetap berdasarkan key, bukan indeks setelah pengurutan nilai. MiniDonut, MethodPie, ikon, dan legend mengikuti aturan yang sama.
3. Aksi: trigger tambah produk disamakan dengan aksi tambah lain memakai accent. DESIGN.md mencatat accent untuk tambah/simpan/bayar dan primary untuk navigasi/filter.
4. Merah tidak lagi dipakai untuk ranking/kategori rutin. Warna biasa memakai token semantik; destructive disimpan untuk bahaya/habis.
5. Panduan memakai kelompok warna yang sama dengan launcher: primary untuk navigasi umum, secondary untuk inventaris, tertiary untuk pengeluaran, dan destructive untuk kondisi bahaya.
6. Hex hardcode UI yang diaudit diganti dengan token; tint status diseragamkan. Palet grafik dikendalikan token CSS dan didokumentasikan.
7. Token `on-primary-fixed` ditambahkan secara resmi dan dipakai oleh state terpilih POS.
