# Audit antislop 002: aplikasi kasir

Tanggal: 2026-10-07. Mode: AFTER, disetujui pengguna.
Dasar: antislop core, antislop-ui, antislop-human, antislop-layoutmobile, dan DESIGN.md.
Arah desain: alat kerja retail berbahasa Indonesia, Material terang dan launcher mobile; ENERGY 1 / RHYTHM 2 / MOTION 1.

## Ringkasan

10 temuan: 8 HIGH, 1 MEDIUM, 1 LOW. Prioritas mengikuti tier antislop, bukan peringkat risiko keamanan.
Audit pertama belum sepenuhnya tertutup: kontras, ukuran target, uppercase, dan palet masih menyisakan masalah. Tidak ada perbaikan kode aplikasi dalam audit ini. Referensi skill ditambahkan ke AGENTS.md sesuai persetujuan.

## Temuan bernomor

### 1. HIGH: tombol aksi hijau gagal kontras teks (R-25)

Alasan: putih pada token accent #059669 hanya **3,77:1**, di bawah AA 4,5:1 untuk teks normal.
- Bukti: app/globals.css:34-35; components/ui.tsx:14; components/login-form.tsx:45; components/product-form.tsx:275; components/pos/pos.tsx:691.
- Teks accent pada surface #FAF8FF juga hanya **3,58:1**, misalnya kembalian POS pada components/pos/pos.tsx:625.
- Teks outline #737686 pada surface #FAF8FF hanya **4,27:1**, termasuk waktu notifikasi pada components/notification-bell.tsx:220.
- Verifikasi: contrast-check.py dari skill antislop-human, bukan perkiraan visual.
- Saran: gelapkan token yang dipakai sebagai teks/latar tombol, lalu ukur ulang default dan hover. Perubahan warna status pada audit 001 belum memperbaiki token accent.

### 2. HIGH: tombol tutup dialog tidak bernama dan fokusnya hilang (R-32, C-4)

Alasan: kontrol bersama untuk menutup dialog tidak dapat dikenali pembaca layar dan tidak menunjukkan fokus keyboard.
- Bukti: components/ui.tsx:182-184, hanya SVG aria-hidden, tanpa aria-label atau teks; focus:outline-none tanpa pengganti.
- Browser: membuka Tambah Produk, memfokuskan tombol X menghasilkan outlineStyle=none dan boxShadow=none. Escape berhasil menutup dialog, tetapi ini tidak memperbaiki tombol X.
- Dampak: seluruh pemakai DialogContent, termasuk produk, pengguna, pelanggan, dan pengaturan stok.
- Saran: beri nama "Tutup dialog" dan indikator focus-visible yang kontras.

### 3. HIGH: unggah foto produk hanya bisa diaktifkan dengan pointer (R-32)

Alasan: area upload berupa div onClick, sedangkan input file display:none dan tidak ada tombol keyboard alternatif.
- Bukti: components/product-form.tsx:158-173.
- Verifikasi: inspeksi kode; div tidak mempunyai tabIndex, semantik tombol, atau handler keyboard.
- Saran: gunakan tombol native yang membuka pemilih file; drag-and-drop tetap sebagai tambahan.

### 4. HIGH: kontrol tanpa nama atau hubungan label yang jelas (R-32, C-4)

Alasan: label visual tidak cukup jika tidak terhubung secara programatik ke kontrol.
- app/(app)/products/page.tsx:128-149: label pencarian, kategori, dan status tidak memakai htmlFor/id; select kategori/status tanpa aria-label.
- app/(app)/reports/page.tsx:359-364: "Dari" dan "Sampai" berupa span. Browser mengukur kedua input date memiliki labels.length=0.
- components/product-form.tsx:222-235: label Kategori/Satuan tidak terhubung ke SelectTrigger.
- app/(app)/sales/page.tsx:137-140: link detail transaksi hanya ikon Eye tanpa nama aksesibel.
- Saran: hubungkan label dengan kontrol; beri link detail nama yang menyebut invoice. Verifikasi lewat accessibility tree.

### 5. HIGH: target sentuh kecil masih tersebar (R-03)

Alasan: pembesaran Button/Input dasar tidak mencakup kontrol custom dan override ukuran.
- components/ui.tsx:182-183: tombol tutup dialog hanya ikon 16px tanpa padding. Browser mengukur sekitar 15,7 x 15,7px ketika animasi pembukaan masih berjalan; ukuran dasar 16 x 16px.
- app/(app)/reports/page.tsx:360-366: input tanggal dan tombol Terapkan mengoverride h-11 menjadi h-9. Browser mengonfirmasi kedua input **36px**.
- app/(app)/reports/page.tsx:306,334,345: preset periode dan ekspor memakai py-2 text-xs tanpa min-height 44px.
- components/notification-bell.tsx:229-235 dan components/pos/pos.tsx:430-434: tombol teks tanpa area sentuh minimum.
- Saran: hit area minimal 44 x 44px untuk kontrol mandiri, dengan jarak memadai; jangan menghitung ukuran ikon sebagai ukuran tombol.

### 6. HIGH: kegagalan notifikasi disamarkan sebagai kosong (R-27)

Alasan: pengguna tidak dapat membedakan tidak ada aktivitas dari server yang gagal dihubungi.
- Bukti: components/notification-bell.tsx:33-46,53-64 mengabaikan response non-OK/error dan menghentikan loading; baris 192-196 lalu menampilkan "Tidak ada notifikasi".
- Browser: request /api/notifications diintersep dengan HTTP 500; panel tetap menampilkan "Tidak ada notifikasi".
- Mutasi gagal juga tidak memberi pesan: markRead/markAllRead pada baris 93-125 hanya rollback atau reload.
- Saran: tampilkan error dan aksi coba lagi; saat polling gagal, data lama boleh dipertahankan dengan penanda gagal diperbarui.

### 7. HIGH: panel notifikasi tidak menutup dengan Escape (R-32, R-26)

Alasan: panel overlay custom tidak mengikuti pola penutupan keyboard yang konsisten dengan dialog lain.
- Bukti: components/notification-bell.tsx:83-91 hanya mendengarkan mousedown di luar panel; tidak ada handler Escape.
- Browser: buka notifikasi lalu Escape, tombol "Tutup notifikasi" tetap terlihat.
- Saran: tangani Escape dan kembalikan fokus ke pemicu; tentukan semantik panel sesuai perilakunya, jangan memasang aria-modal jika bukan modal.

### 8. HIGH: em dash masih ada pada pesan error stok (R-02)

Alasan: string yang dikirim ke UI masih memuat karakter yang dilarang aturan copy antislop.
- Bukti: lib/actions.ts:497, pesan "Stok sudah 0" diikuti em dash dan "tidak bisa dikurangi lagi".
- e2e/verify-fixes.spec.ts:87 juga mengharapkan string lama tersebut.
- Saran: gunakan titik atau koma dan perbarui ekspektasi tes terkait. Komentar developer tidak diperlakukan sebagai masalah UI.

### 9. MEDIUM: uppercase metrik bertentangan dengan arah tipografi (R-06)

Alasan: DESIGN.md:21 membatasi uppercase + tracking untuk status nyata, tetapi judul metrik tetap memakai pola tersebut.
- Bukti: app/(app)/stock/page.tsx:60,147-149 (TOTAL PRODUK, TOTAL STOK, NILAI STOK); app/(app)/reports/page.tsx:86,376-390 (TOTAL PENDAPATAN, LABA KOTOR, RATA-RATA NILAI TRANSAKSI).
- Saran: sentence-case untuk metrik; jangan mengubah singkatan fungsional seperti SKU, QRIS, dan HPP.

### 10. LOW: palet implementasi belum mengikuti palet terkunci (R-29, R-31)

Alasan: warna dipilih dengan hash/menu dan urutan kartu, bukan makna yang konsisten, sementara dokumen membatasi warna inti.
- Bukti: components/home-mobile.tsx:22-39 menggunakan biru, hijau, ungu, amber, merah, magenta, dan teal; tileColor pada baris 45-48 memilih warna dari hash href.
- DESIGN.md:17 melarang hex hardcode halaman, tetapi implementasi masih memakainya. Dokumen sendiri juga memasukkan ungu untuk kartu promo di luar daftar inti, sehingga sumber arah perlu dirapikan.
- Saran: sepakati pemetaan warna semantik ke token yang terbatas atau konfirmasi override palet secara eksplisit. Jangan menghapus identitas Material atau launcher mobile tanpa alasan.

## Bukti runtime dan cakupan

Aplikasi dijalankan melalui server yang sudah aktif di http://localhost:3000, diuji dengan Playwright memakai Microsoft Edge headless. Tidak menjalankan transaksi pembayaran atau penyimpanan data toko.

| Pemeriksaan | Hasil |
| --- | --- |
| Login akun admin fixture | Berhasil menuju / |
| Tur onboarding: Lewati | Berhasil menutup overlay |
| Produk: + Produk Baru | Dialog Tambah Produk terbuka |
| Dialog: fokus tombol X | Indikator fokus hilang, temuan #2 |
| Dialog: Escape | Menutup dialog |
| Notifikasi: buka + respons API 500 | Keadaan kosong palsu, temuan #6 |
| Notifikasi: Escape | Panel tetap terbuka, temuan #7 |
| Laporan: rentang kustom | Input tanggal muncul, tinggi 36px dan label tidak terhubung |
| TypeScript: npx tsc --noEmit | Lulus |
| ESLint: npm run lint | Lulus |

Pemeriksaan overflow tingkat dokumen:
- Lebar **375, 768, 1280px**: /, /pos, /products, /stock, /sales, /notifications, /settings, /users mendapatkan HTTP 200 dan tidak ada overflow horizontal.
- /reports: berhasil pada 768 dan 1280px; navigasi awal 375px sempat ERR_ABORTED. Pemeriksaan ulang /reports?custom=1 pada 375px berhasil tanpa overflow.
- Tambahan pada 375px: /categories, /units, /suppliers, /customers, /purchases mendapatkan HTTP 200 tanpa overflow.
- Tidak ada event pageerror pada putaran kedua pemeriksaan halaman. Ini bukan jaminan seluruh console bebas warning atau semua kontrol telah diuji.
- Tabel inventaris/transaksi/stok memakai scroll container lokal; tidak dianggap gagal hanya karena tabel lebih lebar dari layar.

Runner e2e bawaan belum berjalan dalam sesi ini: perintah npm run dev -- -p 14786 diteruskan sebagai next dev --webpack 14786 dan gagal sebagai direktori proyek. Chromium bundel Playwright juga belum terpasang. Verifikasi browser dilakukan dengan Edge pada server aktif, tanpa mengubah konfigurasi. Suite verify-fixes tidak dijalankan karena mengubah data; walkthrough.spec.ts:154 masih memakai nama bantuan lama, berbeda dari components/guide-dialog.tsx:536.

## Delivery Gate audit

Audit selesai; aplikasi **belum lolos** gate antislop. Dalam mode AFTER, temuan dicatat dan menunggu persetujuan nomor sebelum diperbaiki.

- Hard Gate: R-03/R-25/R-26/R-27/R-32/R-02 belum lolos, dengan bukti #1-8.
- R-24: seluruh tujuan menu nav-items.ts mempunyai route; browser memverifikasi sebagian besar route seperti daftar di atas. Belum mengklaim semua link telah diklik.
- R-35: verifikasi runtime parsial telah dilakukan dan dicatat per aksi; click-through seluruh kontrol, zoom 200%, keyboard mobile nyata, semua state, dan semua role belum lengkap.
- R-37: arah desain dan tiga dial tersedia di DESIGN.md. Tidak mengklaim asal persetujuan arah lama dapat dibuktikan dari kode.
- R-17/R-18/R-36/R-38: ringkasan yang diperiksa memakai query/data aplikasi; tidak ditemukan testimoni atau klaim pemasaran palsu dalam cakupan. Keaslian data produksi tidak diverifikasi.
- R-34: tidak ada toggle tema dalam cakupan, CSS menetapkan tema terang. Pengujian tema kedua tidak berlaku.
- Purpose-Gate: tipografi belum konsisten (#9). Inter dan Lucide memiliki alasan tertulis, sehingga keberadaan library/font itu sendiri bukan temuan.
- Quality Locks: palet belum konsisten (#10). Komposisi kasir, tabel inventaris, launcher mobile, dan grafik memiliki konteks retail; tidak ditandai sebagai template hanya karena memakai sidebar/kartu.
- Liveliness: ENERGY 1 / RHYTHM 2 / MOTION 1 dinyatakan; penilaian visual menyeluruh belum dilakukan dengan screenshot. Tidak memberi PASS visual berdasarkan kode saja.
