# Audit antislop 001 — kasir-v2 — 2026-10-07

Mode: AFTER (audit aplikasi yang sudah jadi, tanpa mengubah kode).
Scope: `app/`, `components/`, `lib/`, `app/globals.css`, `app/layout.tsx`.
Dials: tidak ada `DESIGN.md`, jadi dial tidak bisa diverifikasi (lihat #5).
Cara baca: tiap temuan mencantumkan aturan yang dilanggar (R-XX) dan satu baris alasan. Prioritas mengikuti tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH (Hard Gate, wajib diperbaiki dulu)

### 1. R-02 — Em dash (—) di string user-facing
Alasan: karakter — dilarang di teks mana pun.
Bukti:
- `components/adjust-stock.tsx:60,62,63` — `Stok baru 0 ... — produk menjadi HABIS...`, `... minimum ... — produk tetap/masuk daftar...`
- `components/home-mobile.tsx:203` — `Belum ada penjualan bulan ini — mulai transaksi...`
- `components/guide-dialog.tsx:536` — `aria-label` memakai `—` (`... — panduan ...`)
- Komentar kode ber-— (mis. `components/delta-pill.tsx:4`, `components/home-mobile.tsx:21`) bukan UI text, tapi ikut menambah risiko terbawa ke copy.
Perbaikan: ganti dengan koma, titik, titik dua, atau kurung.

### 2. R-25 — Kontras teks di bawah WCAG AA (terukur dengan contrast-check.py)
Alasan: beberapa pasangan warna lolos di mata tapi gagal di angka.
Bukti (normal text butuh 4.5:1):
- `text-[#00C292]` di `bg-[#E6FFFA]` = 2.20:1 FAIL (dipakai `components/delta-pill.tsx:16`, `app/(app)/page.tsx:34,40,46,435`, `components/home-mobile.tsx:25`)
- `text-[#FF4D4D]` di `bg-[#FFE5E5]` = 2.74:1 FAIL (dipakai `delta-pill.tsx:16`, `home-mobile.tsx:28,39`, `page.tsx:50`)
- `text-white` di `bg-[#00C292]` = 2.30:1 FAIL (dipakai kartu `components/home-mobile.tsx:34-41` + `text-white`)
- `text-white` di `bg-[#FF9800]` = 2.16:1 FAIL, `text-[#FF9800]` di `bg-[#FFF4E5]` = 1.98:1 FAIL (dipakai tile/topColors `home-mobile.tsx:27,38`, restock `home-mobile.tsx:261,270`)
- `text-[#0085FF]` di `bg-[#E8F0FF]` = 3.16:1 FAIL normal (lolos large saja), `text-white` di `bg-[#0085FF]` = 3.62:1 FAIL normal
- Yang lolos: `white` di `brand #2563EB` = 5.17:1 PASS, `#6B46C1` di `#E5E7FF` = 5.26:1 PASS, `#434655` di `#FAF8FF` = 8.88:1 PASS, `#B45309` di `#FFF4E5` = 4.62:1 PASS
Perbaikan: gelapkan teks status (mis. `#0085FF`→`#0053B8`-class, `#00C292`→`#00714D`-class seperti `on-secondary-container`), atau pindahkan angka kecil ke warna yang lolos dan sisakan warna muda hanya untuk ikon besar.

### 3. R-03 — Target sentuh di bawah 44px di banyak kontrol mobile
Alasan: tombol di bawah 44x44 px sulit disentuh ibu jari.
Bukti:
- `components/bottom-nav.tsx:42` — indikator `h-7 w-12` + link `py-2 text-[10px]` (tinggi total di bawah 44px per tab)
- `components/home-mobile.tsx:90` — tombol clear search `h-7 w-7`
- `components/mobile-nav.tsx:28,35` — avatar dan tombol keluar `h-10 w-10` (40px)
- `components/notification-bell.tsx:144,148,177,188` — bell `h-10 w-10`, badge `h-4`, close `h-8 w-8`, spinner `h-4 w-4`
- `components/table-pagination.tsx:165,176` — input dan select `h-9` (36px)
- `components/ui.tsx:22,24` — `buttonSizes sm h-9`, `icon h-10 w-10`
Perbaikan: naikkan hit area ke 44px via padding (visual boleh kecil, hit box tetap 44px) dan beri gap antar target rapat.

### 4. R-27 — Tidak ada loading.tsx / error.tsx per route + skeleton tak terasa
Alasan: tiap UI data wajib punya empty, loading, dan error yang terlihat.
Bukti:
- `glob **/loading.tsx` = tidak ada file, `glob **/error.tsx` = tidak ada file (hanya milik `node_modules/@auth`)
- `components/charts/sales-chart.tsx:46` — loading hanya `<div class="h-64 animate-pulse bg-muted" />` tanpa teks (pembaca layar mengira halaman macet)
- Empty state ada dan bagus di beranda (`app/(app)/page.tsx:457,486,613,650,666`), tapi loading/error level route tidak ada
Perbaikan: tambah `app/(app)/loading.tsx` (dengan teks "Memuat..."), `error.tsx` (pesan + tombol coba lagi), dan beri teks pada skeleton chart.

### 5. R-37 — Tidak ada DESIGN.md / dial tidak dideklarasikan
Alasan: tanpa arah gaya, hasil adalah draft bukan deliverable.
Bukti: `glob DESIGN.md` = tidak ada; tidak ada baris `Dial: ENERGY x / RHYTHM y / MOTION z` di repo.
Konteks: aplikasi sebenarnya konsisten (Material 3 seed blue, Inter, super-app mobile), jadi ini dokumentasi yang hilang bukan desain yang hilang.
Perbaikan: tulis `DESIGN.md` 1 halaman (identitas, palet inti, tipografi Inter alasannya, dial mis. ENERGY 1 / RHYTHM 2 / MOTION 1) lalu catat override bila ada pola bernama yang dipertahankan.

## MEDIUM (Purpose-Gate, teknik boleh dipakai bila ada alasan tertulis)

### 6. R-04 — Satu library ikon (Lucide) untuk semua + ikon generik Sparkles
Alasan: glyph boleh relevan, tapi tampilan satu library yang seragam tanpa alasan tertulis adalah default.
Bukti:
- `package.json:27` — `lucide-react`; dipakai di `nav-items.ts:1-17`, `page.tsx:8-18`, `home-mobile.tsx:5-17`, `pos.tsx:5`
- `components/onboarding-tour.tsx:271` — `<Sparkles>` (keluarga sparkle/star/magic yang dilarang sebagai default)
- Ikon kasir (`Banknote` untuk Tunai, `QrCode` untuk QRIS, `ArrowLeftRight` untuk Transfer di `pos.tsx:53-57`) sebenarnya relevan, hanya belum ditulis alasannya
Perbaikan: tulis satu baris relevansi per ikon kunci di `DESIGN.md`, ganti `Sparkles` onboarding dengan ikon panduan yang relevan (mis. `Map`/`Compass`) atau hapus.

### 7. R-06 — Uppercase + tracking lebar dipakai di mana-mana tanpa alasan
Alasan: label uppercase `tracking-wider/wide` hanya untuk status/section, bukan default semua label.
Bukti: `sidebar.tsx:34` (`PENJUALAN BARU`), `home-mobile.tsx:107,260` (`Hari Ini`, `Habis/Menipis`), `page.tsx:435` (`Terlaris`), `sales/page.tsx:132`, `reports/page.tsx:581`, `guide-dialog.tsx:647,665`, `pos/confirm.tsx:232,247`, `stock/page.tsx:60`
Perbaikan: batasi ke status nyata + tulis alasannya; sisanya jadi sentence-case biasa.

### 8. R-08 — Panah ArrowRight di hampir tiap CTA
Alasan: panah bukan identitas default tiap tombol.
Bukti: `app/(app)/page.tsx:426,573,627,661` (`Lihat Laporan`, `Lihat Semua` x2, `Kelola Stok`), `home-mobile.tsx:198,242` (`Lihat semua`, `Kelola stok`), `pos.tsx` mengimpor `ArrowRight`
Perbaikan: simpan panah hanya untuk aksi yang butuh isyarat arah, sisanya tanpa panah.

### 9. R-09 — Capsule badge yang perlu surat izin fungsi
Alasan: badge hanya bila ada status/label nyata, dengan kebutuhan tertulis.
Bukti: `home-mobile.tsx:107` (`Hari Ini`), `page.tsx:435` (`Terlaris` + ikon), `home-mobile.tsx:216` (`#1`), `home-mobile.tsx:260` (`Habis/Menipis`), `guide-dialog.tsx:634` (`hitCount`)
- `Hari Ini` menduplikasi konteks hero; `#1` + `Terlaris` ganda di kartu yang sama
Perbaikan: hapus/gabung yang duplikatif (`Hari Ini`, `#1` vs `Terlaris`), sisakan status stok yang nyata dan tulis kebutuhannya.

### 10. R-14 — Tiga StatCard identik (ukuran, ikon, padding, layout)
Alasan: kartu seragam meratakan hierarki padahal bobot konten beda.
Bukti: `app/(app)/page.tsx:368-397` — `StatCard` Penjualan/Transaksi/Pengeluaran memakai struktur sama persis (`StatCard` di `page.tsx:72-105`)
Perbaikan: beri perlakuan flagship ke metrik utama (mis. Penjualan full-width atau angka lebih besar) dan tulis alasan hierarkinya.

## LOW (Quality Locks + code comments)

### 11. R-11 — Hampir semua sudut memakai pill (rounded-full)
Alasan: radius adalah alat hierarki, bukan default semua elemen.
Bukti: search `home-mobile.tsx:84` (`rounded-full`), tombol clear `rounded-full`, hero CTA `rounded-xl` vs badge `rounded-full`, `bottom-nav.tsx:42`, `ui.tsx:130` (`Badge rounded-full`), `table-pagination.tsx:165,176`, avatar `rounded-full` di `layout.tsx:41`, `mobile-nav.tsx:28`
- Sistem di `ui.tsx` sendiri konsisten (`rounded-lg` button/input, `rounded-xl` card/dialog), tapi pemakaian di halaman mencampur `rounded-full/2xl/3xl` tanpa skala tertulis
Perbaikan: kunci skala radius di `DESIGN.md` (mis. input/button lg, card xl, pill hanya badge/status) lalu samakan.

### 12. R-29 — Palet aktif >5 warna tanpa sistem tertulis
Alasan: batas aktif 2-3 inti + 1 aksen; netral tidak dihitung.
Bukti:
- `page.tsx:38-51` — `rankColors` 5 + `categoryColors` 5 (hex hardcode `#E6FFFA/#00C292`, `#E5E7FF/#6B46C1`, `#FFE5E5/#FF4D4D`, `#FFF4E5/#FF9800`, `#E8F0FF/#0085FF`)
- `home-mobile.tsx:23-41` — `tilePalette` 7 + `topColors` 6 (tambah `#F3E5F5/#8E24AA`, `#E0F2F1/#00897B`)
- `globals.css:24-65` — `primary #004AC6`, `primary-container #2563EB`, `secondary #006C49`, `accent #059669`, `tertiary #784B00/#996100`, `brand #2563EB`
Perbaikan: petakan ke token (`primary/secondary/tertiary/destructive` + 1 aksen), hapus hex hardcode di halaman.

### 13. R-31 — Tidak ada alasan tertulis per keputusan besar
Alasan: tiap keputusan (warna, layout, tipografi, spacing, kartu, ikon) wajib satu baris alasan.
Bukti: tidak ada `DESIGN.md` / komentar alasan di `page.tsx`, `home-mobile.tsx`, `globals.css`
Perbaikan: tambah bagian "Alasan" 6 baris di `DESIGN.md`.

### 14. Code comments — Separator dekoratif di ui.tsx
Alasan: banner `/* ---- X ---- */` adalah dekorasi, bukan informasi (skill antislop-code).
Bukti: `components/ui.tsx:11,56,85,97,116,134,162,202,256` — `/* ---------------- Button/Input/Label/Card/Badge/Table/Dialog/Select/Dropdown ---------------- */`
Perbaikan: ganti satu baris polos (`/* Button */`) atau hapus bila label tidak menambah info. Komentar lain di repo justru bagus (menjelaskan kenapa, mis. `pos.tsx:13-15` soal sessionStorage, `page.tsx:60` soal timezone, `layout.tsx:22-24` soal print).

### 15. R-34/R-21 — Sisa kelas dark: padahal tema gelap dihapus
Alasan: mode yang dikirim harus bekerja; kode mati tema menambah bingung.
Bukti: `globals.css:9-14` menyatakan tema gelap dihapus (keputusan tercatat, bagus), tapi `page.tsx:369,379,389` masih `dark:bg-...`, `ui.tsx:148` masih `dark:even:...`
Perbaikan: hapus semua `dark:` yang mati agar tidak dikira mendukung dark mode.

### 16. R-27/C-4 — Empty state ada tapi belum semua memberi aksi berikutnya
Alasan: empty yang baik menyebut sebab + satu aksi pengisi.
Bukti (sudah bagus): `home-mobile.tsx:202-204` (`Belum ada penjualan... mulai transaksi pertama di Kasir`), `home-mobile.tsx:165-172` (filter kosong + petunjuk tab bawah)
